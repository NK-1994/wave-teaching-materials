モデル

巻き \(j\)（\(j = 0, 1, \dots, N-1\)）を質量 \(m = M/N\) の質点、隣り合う巻きの間をバネ定数 \(\kappa = (N-1)K\) のバネとします。巻き \(0\) はクランクで動かし、巻き \(N-1\) は壁に固定します。

\[ m\,\ddot u_j = \kappa\,(u_{j+1} - 2u_j + u_{j-1}) - m\Gamma\,\dot u_j + (\text{接触力}) \]

隣り合う巻きの中心間の距離が1巻きの厚み \(L_0/N\)（\(L_0 = 5.40\ \mathrm{cm}\) は自然長＝コイルが密着した長さ）より小さくなると、強いバネで押し返す接触力がはたらきます。クランクは半径 \(A\) の円板に長さ \(l\) の連接棒をつなぎ、レール上のスライダーを往復させる機構です。巻き \(0\) の変位は

\[ u_0 = A\cos\theta + \sqrt{l^2 - A^2\sin^2\theta} - l \simeq A\cos\theta - \frac{A^2}{4l}\,(1 - \cos 2\theta), \qquad \theta = 2\pi f t \]

で、単振動に振動数 \(2f\) の成分（振幅 \(A^2/4l\)）が混ざります。\(2f\) が共鳴振動数に近いと、この成分でも定常波が立ちます。重力と摩擦は、減衰率 \(\Gamma\) にまとめています。

\[ f_n = \frac{1}{\pi}\sqrt{\frac{\kappa}{m}}\,\sin\frac{n\pi}{2(N-1)} \simeq \frac{n}{2}\sqrt{\frac{K}{M}}, \qquad \frac{B}{A} \simeq \frac{2Q}{n\pi},\quad Q = \frac{2\pi f_n}{\Gamma} \]

共鳴曲線と理論の振幅は、接触力を除いた線形の離散モデルを、振動数 \(f\) の成分（振幅 \(A\)）について厳密に解いたものです。コイルが接触し始めると、シミュレーションの振幅は理論より小さく頭打ちになります。
